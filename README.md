# 📝 Full-Stack Blog Application

A complete full-stack blog web application built with Node.js, Express, MongoDB Atlas, and JavaScript as part of the Codomax Digital Solutions Internship.

## 🚀 Live Demo
- **Live Application:** [https://my-blog-app-onf4.onrender.com/](https://my-blog-app-onf4.onrender.com/)

## ✨ Key Features
- **User Authentication:** User Registration & Login powered by JWT (JSON Web Tokens).
- **Protected Dashboard:** Access restricted to authenticated users only.
- **Full CRUD Operations:** Create, Read, Update, and Delete blog posts.
- **Responsive UI:** Clean and simple frontend interface.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Authentication:** JWT (JsonWebToken)
- **Hosting / Cloud Deployment:** Render
